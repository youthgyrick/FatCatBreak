# AWS AI/ML Specialist BD Interview Deck

这是一个无外部依赖的 HTML 演示文稿，内容定位为 **Enterprise AI Transformation Proposal**。

## 本地预览

直接用浏览器打开 `index.html`，或在仓库根目录运行：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173/presentation/aws-ai-ml-specialist-bd/
```

## 演示控制

- `←` / `→`、`Page Up` / `Page Down`：翻页
- `Space`：下一页
- `Home` / `End`：首尾页
- `F`：进入或退出全屏
- `O`：打开或关闭总览
- 移动端支持左右滑动

## 打印 / 导出 PDF

在 Chromium、Chrome 或 Edge 中打开后使用浏览器打印功能，选择“另存为 PDF”。样式会自动切换为每页一张 16:9 幻灯片。

## 文件

- `index.html`：18 页演示内容与语义结构
- `styles.css`：视觉系统、架构图、响应式与打印样式
- `script.js`：翻页、全屏、URL hash、触控与总览功能

## 依赖

无。演示不加载外部字体、CDN、图片或 JavaScript 库，可离线运行。
