# 初中化学记忆助手

一个面向初中生的纯前端化学记忆网页，用于学习前 20 号元素、常见化合价、原子团和化学式。

## 功能

- **首页**：展示今日答题数、正确率、错题数量和到期复习数量
- **学习模式**：按元素、化合价、原子团、化学式、方程式或混合挑战过滤闪卡和测验
- **速查**：搜索并筛选固定价、可变价、原子团和常见化学式
- **元素记忆**：前 20 号元素顺序卡片、顺序填空和缺项挑战
- **口诀**：化合价口诀及可展开、收起的逐句解释
- **化学方程式**：23 条常见反应，按 Level 1–3 展示反应名称、方程式、条件和现象
- **闪卡**：使用洗牌队列快速记忆化合价、原子团和化学式
- **测验**：化合价、元素顺序、化学式、名称反向和化学方程式填空；支持上一题回看、连续 Enter 和错误答案知识解释
- **名称判定**：中文名称题支持中文数字与阿拉伯数字混合填写，如“五氧化2磷”
- **专注模式**：隐藏导航并放大题目、输入框和操作按钮
- **问一问**：通过本地知识库回答常见化学问题，并提供简单的化学式拼写纠错
- **错题本**：按照 10 分钟、1 天、3 天、7 天、14 天和 30 天安排复习
- **统计**：熟练度星级、连续学习、类型掌握情况、易错知识点和最近复习

闪卡、元素训练和综合测验均使用 Fisher–Yates 洗牌队列，同一轮内不会重复出现同一道题。全部学习数据仅保存在浏览器 `localStorage` 中。

化学方程式默认只开放 Level 1。当前等级至少完成 8 道方程式题且正确率达到 80% 后，会依次解锁 Level 2 和 Level 3；综合测验会优先安排当前最高已解锁等级的方程式。

“问一问”不会连接 AI、网络或任何外部 API。所有回答仅来自 `app.js` 中的元素、化合价、原子团、化学式和方程式数据。

## 本地运行

无需安装依赖或构建。直接双击 `index.html` 即可运行。

也可以在项目目录启动一个本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

```text
README.md   项目说明
```

## 本地数据

- `chem-memory-mistakes-v2`：跨题型错题和遗忘曲线进度
- `chem-memory-stats-v2`：每日答题统计
- `chem-memory-equation-progress-v1`：化学方程式等级、答题数和正确率
- `chem-memory-chat-history-v1`：“问一问”的最近 40 条对话消息
- `chem-memory-mastery-v1`：每个知识点的正确、错误、复习等级和熟练度数据
- `chem-memory-study-mode-v1`：当前学习模式

清除当前页面的浏览器站点数据即可重置学习记录。
