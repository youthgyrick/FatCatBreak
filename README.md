# 化合价记忆助手

一个面向初中生的轻量化合价背诵练习网页，包含速查、口诀、闪卡、填空测验和带遗忘曲线的错题复习。

## 功能

- 首页展示当天答题数、正确率和待复习错题数
- 分类速查常见元素、可变价元素与常见原子团
- 口诀卡片支持显示或隐藏逐句解释
- 随机闪卡可标记“记住了”或“不熟悉”
- 填空测验支持多种可变价答案格式和“部分正确”判断
- 错题本按 10 分钟、1 天、3 天、7 天、14 天、30 天安排复习
- 全部学习数据保存在浏览器 `localStorage`，无需账号或后端
- 自适应桌面与手机屏幕

## 本地运行

这是一个纯静态项目，可以直接双击 `index.html` 打开。为获得更稳定的浏览器体验，也可以在项目目录启动静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 数据说明

应用使用以下 localStorage 键：

- `valence-helper-mistakes-v1`：错题与遗忘曲线进度
- `valence-helper-stats-v1`：按日期保存的答题统计

清除浏览器中该站点的数据即可重置全部学习记录。
